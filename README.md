# Islam Sayed Portfolio

TanStack Start portfolio site with React, file-based routes, responsive styling, and SSR-ready Vite configuration.

## Run locally

```bash
npm install
npm run dev
```

Routes:

- `/` — portfolio home
- `/about` — about and skills
- `/blog` — article preview
- `/for-designers` — coming soon page

Build with `npm run build` and preview with `npm run start`.
